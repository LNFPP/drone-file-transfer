# Drone File Transfer (Mac)

Copies DJI drone footage into community/location folders using Flight Log CSVs exported from the Lot Shots Drone app.

**Download:** https://github.com/LNFPP/drone-file-transfer/releases/latest/download/DroneFileTransfer-mac.zip

Unsigned app: on first open, go to System Settings → Privacy & Security → Open Anyway.

Built automatically by GitHub Actions on every push to `main` (universal: Apple Silicon + Intel, macOS 13+).
